## [不动核心代码，AI 优化构建让 7-Zip 压缩提速 97%](https://www.infoq.cn/article/Qp04AcNuAM8YqtVQHyu3?utm_source=rss&amp;utm_medium=article) ⭐️ 8.0/10

在一项有记录的实验中，一位自称“外行”的开发者与 AI 合作，在不改动核心代码的情况下，将 7-Zip 的压缩速度提升了 97%。这一提升来自 AI 引导的构建优化——即挑选和调优 PGO、LTO 等编译器选项——而非任何算法层面的改动。 这表明仅靠构建期优化就能解锁显著的性能提升，对各类软件项目都有直接借鉴意义。同时，它也凸显了 AI 在性能工程中日益重要的作用，可能影响开发者后续的优化思路。 报道称，这次提升来自用 AI 挑选和调优编译器优化选项，其中包含配置文件引导优化（PGO）和链接时优化（LTO）。由于原文摘要未提供更深入的细节，具体的参数组合和基准测试条件尚不明确。

rss · InfoQ 中文 · 8月5日 18:45

**背景**: 编译器除了默认的-O2/-O3 之外，还可以利用反馈导向的技术进一步优化程序。PGO 会从代表性运行中收集运行时分析数据，再反馈给编译器以指导优化决策；LTO 则在链接阶段进行跨模块的全局分析。这些技术无需改动源代码，也能带来明显的性能改善。

## [恶意 npm 包迫使 GitHub 暂停自动升级](https://www.infoq.cn/article/mHKwxgo5SqfmtZEESCrN?utm_source=rss&amp;utm_medium=article) ⭐️ 8.0/10

一个恶意 npm 包在两小时内造成严重破坏，据报道影响数十亿次下载，GitHub 随即暂停自动依赖更新以防止进一步扩散。此次暂停针对的是 GitHub 用于依赖更新的自动拉取请求工具 Dependabot。 此事件凸显了软件供应链攻击日益严重的威胁，一个被攻陷的软件包就能波及无数项目。GitHub 暂停自动化更新，等于承认自动化虽然便捷，但也可能扩大恶意代码的影响范围——这会影响依赖 npm 的数百万开发者和组织。 GitHub 的 Dependabot 会在新依赖版本可用或检测到漏洞时自动创建拉取请求；暂停它可以降低自动合并受污染版本的风险。此次攻击与近期 npm 供应链事件相符，例如维护者账户被入侵导致 Keyv 及其相关包被注入恶意代码。

rss · InfoQ 中文 · 8月5日 18:00

**背景**: npm 是 JavaScript 的默认软件包注册表，被数百万个项目使用；供应链攻击是指攻击者发布或入侵软件包以注入恶意代码，这些代码会在安装或更新时执行。Dependabot 是 GitHub 原生工具，可自动更新依赖，让开发者更容易保持补丁更新，但同时也可能成为软件注册表被攻陷后大规模传播的潜在途径。

## [Mysk：WebKit 缺陷导致 Apple Private Relay 与 OnionBrowser 泄露用户 IP](https://www.techmeme.com/260805/p32#a260805p32) ⭐️ 8.0/10

Mysk 的安全研究人员发现，由于苹果 WebKit 浏览器引擎存在一系列问题，iCloud Private Relay 可能泄露用户的真实 IP 地址。同一缺陷也影响 iOS 上基于 Tor 的 OnionBrowser，削弱了这两款工具的隐私保护能力。 Private Relay 的设计初衷是向网站隐藏用户 IP 地址，因此该泄露破坏了苹果对用户的核心隐私承诺。同时它也暴露了 iOS 上的 Tor 用户，使这一漏洞对注重隐私的用户和安全社区具有重要意义。 研究人员发现的是一组问题而非单一漏洞，根本原因在于 WebKit——这是所有 iOS 浏览器都必须使用的引擎。据报道，苹果尚未针对这些问题发布修复。

rss · Techmeme · 8月5日 17:40

**背景**: iCloud Private Relay 是苹果 Safari 内置的隐私功能，它通过两个代理服务器路由流量，确保没有任何一方（包括苹果）能同时看到用户身份和访问的网站。WebKit 是驱动 Safari 的浏览器引擎，并且根据苹果 App Store 规则，iOS 上的所有浏览器（包括通过 Tor 匿名网络路由流量的 OnionBrowser）都必须使用它。由于所有 iOS 浏览器都依赖 WebKit，该引擎的缺陷可能同时影响多项隐私保护工具。
