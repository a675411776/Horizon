## [移除 React 改用 HTMX：一个案例研究](https://misago-project.org/t/removing-reactjs-from-the-codebase-and-adapting-htmx-for-ui-interactivity/1267/) ⭐️ 8.0/10

Misago 论坛软件项目决定从代码库中移除 React.js，改用 HTMX 实现 UI 交互，从单页应用模式转向服务器端渲染 HTML 结合超媒体驱动的交互方式。 这一案例研究突显了开发者从重型 JavaScript 框架转向更简单的超媒体解决方案（如 HTMX）的趋势，这可以降低复杂性、提升性能并减少维护成本，尤其适用于论坛这类内容密集的应用。 HTMX 是一个小型（约 14k min.gz&\#x27;d）、无依赖的 JavaScript 库，允许通过 HTML 属性直接使用 AJAX、CSS 过渡、WebSocket 和服务器发送事件。该项目相比 React 减少了 67%的代码量，但部分用户报告在处理大型 HTML 响应时存在性能问题。

hackernews · Ralfp · 7月27日 09:58 · [社区讨论](https://news.ycombinator.com/item?id=49067301)

**背景**: HTMX 是一个开源前端库，通过自定义属性扩展 HTML，无需编写自定义 JavaScript 即可实现动态行为。它采用超媒体方法，将服务器端渲染的 HTML 片段交换到 DOM 中，与 React 的客户端组件模型形成对比。这种方法符合服务器端渲染模式，并降低了客户端复杂性。

## [libsm64 将超级马力欧 64 转化为可复用库](https://github.com/libsm64/libsm64) ⭐️ 8.0/10

libsm64 项目发布了一个软件库，它打包了来自《超级马力欧 64》的移动和渲染代码（通过 SM64 反编译项目提取），从而使马力欧可以轻松嵌入到其他游戏引擎中。 这实现了前所未有的跨游戏集成，例如马力欧在《半条命 2》中出现，并展示了游戏反编译和代码复用的创意潜力，无需依赖专有平台或区块链炒作。 该库基于 n64decomp 社区对《超级马力欧 64》的完整反编译构建，为开发者提供了干净的 C 语言 API。用户需合法提供游戏 ROM 副本来提取资产。

hackernews · klaussilveira · 7月27日 10:04 · [社区讨论](https://news.ycombinator.com/item?id=49067352)

**背景**: 《超级马力欧 64》于 1996 年发布，是一款里程碑式的 3D 平台游戏。SM64 反编译项目将其二进制代码逆向为可读的 C 源代码，从而支持移植和修改。libsm64 进一步将该代码抽象为一个与原始游戏引擎解耦的库，使得马力欧可以放入任何项目中。
