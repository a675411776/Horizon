## [GitHub Copilot Autofix 引入漏洞，导致 Snowflake 的 Jira 被入侵](https://www.wiz.io/blog/red-agent-snowflake-copilot-cicd-bug) ⭐️ 8.0/10

Wiz 的研究人员报告称，GitHub Copilot Autofix 在 Snowflake 的一个 GitHub Actions 工作流中生成了存在漏洞的代码更改，导致可能入侵 Snowflake 的 Jira 实例。该漏洞是 CI/CD 工作流 YAML 文件中 shell 命令的模板注入。 这一事件凸显了未经审查的 AI 生成代码所带来的供应链安全风险，尤其是在 AI autofix 建议被合并到处理敏感凭据和系统的 CI/CD 流水线时。任何使用 Copilot Autofix 的组织都会受到影响，因为一个看似合理但有缺陷的修复可能在审查者发现之前就扩大了攻击面。 存在漏洞的更改出现在 GitHub Actions 工作流（如 jira\_issue.yml）中，其中问题标题或正文在未正确转义的情况下被嵌入 shell 命令，从而导致任意命令注入。像 zizmor 这样的静态分析工具可以检测 GitHub Actions 仓库中的此类模板注入问题。

hackernews · galnagli · 8月17日 14:18 · [社区讨论](https://news.ycombinator.com/item?id=49331423)

**背景**: GitHub Copilot Autofix 是一个使用 AI 分析代码扫描警报并提供修复建议的功能，旨在帮助开发者更快地修复漏洞。然而，CI/CD 流水线已成为软件供应链攻击的主要目标，因为它们通常持有可用于部署和发布代码的凭据。这一事件表明，如果 AI 生成的修复未经过适当审查，可能会无意中引入新的漏洞。

## [重排任务顺序，GPU 利用率提升 33 个百分点](https://huggingface.co/blog/Dharma-AI/gpu-management-pt2) ⭐️ 8.0/10

Dharma-AI 在 Hugging Face 博客上发表文章，展示了在同一 GPU 集群上仅重新调整工作负载的调度顺序，就能将利用率提升 33 个百分点，且无需增加任何硬件。这一变化纯粹来自作业在集群 GPU 上的放置顺序。 这很重要，因为 GPU 集群是机器学习领域最昂贵的基础设施之一，利用率提升直接降低每次实验的成本。它表明，调度和排序策略无需资本支出即可带来巨大的效率提升。 文章中的案例研究显示，在固定集群上将利用率提升 33 个百分点，凸显了工作负载排序对 bin-packing（装箱）和碎片化的影响。原始博客文章中详细说明了具体的排序策略和集群配置。

rss · Hugging Face Blog · 8月17日 19:46

## [SineKAN：用正弦激活函数替代 B 样条的 KAN 变体](https://www.reddit.com/r/MachineLearning/comments/1vqdode/r_sinekan_kolmogorovarnold_networks_using/) ⭐️ 7.0/10

Reddit 上一篇帖子介绍了 SineKAN，这是一种使用正弦激活函数而非 B 样条的 Kolmogorov-Arnold 网络变体。帖子附上了 arXiv 论文（2407.04149）、GitHub 仓库以及 MDPI 期刊《Mathematics》上同行评审论文的链接。 KAN 作为 MLP 的替代架构广受关注，因此探索正弦等替代激活函数与当前寻找性能更好、可解释性更强架构的研究方向密切相关。这项渐进式且经过同行评审的贡献可能影响 KAN 在符号回归、科学计算和函数逼近等任务中的设计方式。 arXiv 论文题为“SineKAN: Kolmogorov-Arnold Networks Using Sinusoidal Activation Functions”，正式论文发表于《Mathematics》2025 年第 13 卷第 19 期，文章编号 3157。GitHub 仓库（ereinha/SineKAN）提供了实现；作者提到使用正弦函数的想法此前已有人尝试过，但分享出来是为了引发进一步讨论。

reddit · r/MachineLearning · /u/jacobgorm · 8月17日 00:46

**背景**: Kolmogorov-Arnold 网络（KAN）是一类受 Kolmogorov-Arnold 表示定理启发的神经网络架构，该定理指出多元函数可以表示为若干一元函数之和。与在线性权重组合上使用固定激活函数的多层感知机（MLP）不同，KAN 用可学习的一元函数替代权重，这些函数通常由 B 样条构建。B 样条是一类分段多项式基函数，因其光滑性和局部支撑性而广泛用于数值分析和计算机图形学。
